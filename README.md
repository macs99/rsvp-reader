# RSVP速読

青空文庫の作品を、文節ごとに画面中央へ次々と表示して読む Web アプリです。
Windows の Chrome と iPhone の Safari で使えます。

## 使い方

- 「作品」から、同梱の「蜘蛛の糸」、Dropbox の専用フォルダーの作品、青空文庫の zip / txt、貼り付けた文章のどれかを開きます
- 再生・停止：Space キー／画面中央をタップ／「再生」ボタン
- 1単位戻る・進む：← → キー／左右にスワイプ（左へ払うと進む、右へ払うと戻る）
- 段落の頭へ戻る：Shift+← ／「⇤段落」ボタン（すでに段落の頭にいるときは、前の段落へ）。次の段落へ：Shift+→
- 最初へ：「⏮」ボタン
- 速度：画面下のつまみ／↑ ↓ キー（50字/分ずつ、300〜2,000字/分）
- 縦表示と横表示の切り替え：V キー／「設定」
- 「設定」の「表示」：ルビ（同じ語すべて／原文どおり／なし）、まとめる（1〜3文節）、最小字数、句読点で間をとる、名前を色分け、人物ラベル（名前の読みを章ごとに最初の3回・1回・毎回・なし）、名前で少し長く（1.25倍）、縦表示、注視点ガイド
- 名前：作品ごとに「設定」の「名前」欄で直せます。最初は本文から自動で探した候補が入ります
- 読んだ位置と名前は、作品ごとにこのブラウザーと Dropbox（接続しているとき）に保存されます。「何字中何字目」を押すと、段落や字数を指定して移動できます

## 構成

- `index.html`：アプリ本体（ビルド工程なし）。BudouX と JSZip は CDN から読み込みます。BudouX を読み込めないときは、句読点と助詞で区切る簡易処理に切り替わります
- `texts/kumo_no_ito.txt`：芥川龍之介「蜘蛛の糸」（青空文庫 `92_ruby_164.zip` の文字コードを UTF-8 に変えたもの。注記は残してあり、アプリ側で取り除きます）
- `gaiji.json`：外字注記（「第3水準1-87-71」など）を Unicode の文字に置き換える表（4,354字）。Project X0213 の [JIS X 0213:2004 vs Unicode mapping table](http://x0213.org/codetable/jisx0213-2004-std.txt)（自由に使用・改変・再配布可）から `tools/build-gaiji.mjs` で作成。読み込めないときは外字を取り除きます
- `tools/check.mjs`：変換後の記号の残りと、表示単位の長さを数える検証用スクリプト

```
cd tools
npm install
node check.mjs
```
